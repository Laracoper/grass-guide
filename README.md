# 🌿 Grass Guide — Полное руководство по токену $GRASS

**Grass Guide** — это информационный сайт-сателлит, созданный специально для привлечения поискового трафика и монетизации через реферальную программу проекта *Grass Network*. Сайт содержит подробные инструкции по выводу токенов ($GRASS), анализу текущей эпохи (Epoch) фарминга, прогнозам курса монеты и новостям экосистемы. Каждая страница оптимизирована под ключевые запросы: «как вывести токены grass», «актуальная эпоха grass» и другие.

### О проекте Grass Network

*Grass Network* — это DePIN-проект (*Decentralized Physical Infrastructure*) на блокчейне Solana. Он позволяет пользователям зарабатывать за счет предоставления неиспользуемой полосы пропускания интернета для сбора публичных веб-данных, необходимых для обучения нейросетей. В обмен участники получают вознаграждение в виде очков и токена $GRASS.

Сайт **Grass Guide** объясняет механику работы сети простым языком, помогает новичкам разобраться с процессом вывода средств и предоставляет актуальную информацию о состоянии сети.

## Технологии и структура сайта

Проект реализован как статический HTML-сайт без использования серверного рендеринга или сложных CMS. Это обеспечивает высокую скорость загрузки страниц и идеальные показатели SEO.

- **HTML/CSS:** Страницы написаны вручную с использованием чистого CSS3. Для адаптивности используется Flexbox и переменные CSS (`--max-content-width`).
- **JavaScript:** Минимальный функционал только для копирования рефссылки в буфер обмена. Используется современный API `navigator.clipboard.writeText()`.
- **Структура файлов:** Весь контент хранится в папке верхнего уровня. Нет сложной иерархии директорий. Файлы изображений лежат в `/img/`, стили — в одном файле `style.css`. Такой подход упрощает поддержку и деплой.
- **Хостинг:** Проект размещен на *GitHub Pages*, что дает бесплатные SSL, доменное имя вида `username.github.io/project-name` и автоматическую сборку при каждом коммите.
- **SEO:** На каждой странице прописаны уникальные мета-теги `<title>` и `<meta name="description">`. Добавлены Open Graph теги для красивого отображения ссылок в соцсетях. Сгенерированы файлы `sitemap.xml` и `robots.txt`.

## Как работает этот проект?

Сайты такого типа называются сателлитами. Их цель — занять высокие позиции в поиске по низкочастотным запросам и привести пользователей к целевому действию — регистрации по вашей реферальной ссылке.

В данном случае:
- Пользователь находит ответ на свой вопрос («Как вывести токены Grass?»).
- В процессе чтения он видит вашу реферальную ссылку с кнопкой «Копировать».
- При переходе пользователя по этой ссылке вы получаете бонусные очки от Grass Network.

> ⚠️ Важно! Этот проект не является официальным ресурсом Grass Network. Вся информация представлена исключительно в ознакомительных целях и основана на открытых данных из общедоступных источников.
